# Boutique Anshi — Tienda Web

Sitio web de demostración para **Boutique Anshi**.

## Cómo ver el sitio

1. Abre el archivo `index.html` en tu navegador (doble clic o arrástralo).
2. También puedes subirlo a cualquier hosting gratuito (Netlify, Vercel, GitHub Pages, etc.).

## Características

- Diseño elegante con los colores de tu logo (beige + marrón oscuro)
- Logo integrado
- Catálogo de productos con filtros por categoría
- Modal de detalle de producto
- Sección "Nosotros" y formulario de contacto
- **Panel de administración** (ícono ⚙ arriba a la derecha) para agregar nuevos productos
- Productos guardados en el navegador (localStorage)
- Totalmente responsive (móvil, tablet y escritorio)

## Cómo agregar tus productos reales

1. Haz clic en el botón ⚙ (arriba a la derecha)
2. Completa el formulario:
   - Nombre del producto
   - Precio
   - Categoría
   - URL de la imagen (puedes subir la imagen a Imgur, Cloudinary o cualquier servicio y pegar el enlace)
   - Descripción
3. El producto se agregará automáticamente a la tienda

## Personalizar datos de contacto

Edita el archivo `index.html` y busca la sección `#contacto` para cambiar:
- Dirección
- Número de WhatsApp
- Email
- Horario

También puedes actualizar los enlaces de redes sociales en el footer.

## Notas importantes

Este es un **sitio de demostración frontend**. Los productos se guardan solo en el navegador del usuario.

Para una tienda real con:
- Base de datos de productos
- Pagos (Mercado Pago, Stripe, etc.)
- Gestión de stock e inventario
- Panel de administración seguro

Te recomiendo plataformas como:
- **Shopify**
- **Tienda Nube**
- **WooCommerce** (WordPress)
- **Medusa.js** o **Saleor** (más avanzado)

O contactar a un desarrollador para crear un backend personalizado.
